# DevNote

Фреймворк для разработки Unity-игр с MVC-архитектурой, DI-подобным внедрением зависимостей и системой платформенных сервисов.

## Основные возможности

- **Context** — система внедрения зависимостей через `Holder` и регистрацию в `MainSceneContext` / `ProjectContext`
- **Configs** — централизованное хранение ресурсов и параметров в ScriptableObject (Resources)
- **Controller / View** — разделение игровой логики (Controller) и визуала с возможностью пользовательского ввода (View)
- **Viewer** — кеширование и показ/скрытие View-элементов (в т.ч. из префабов)
- **GameState** — единое хранилище прогресса игрока с парсингом в/из строк и интеграцией с ISave
- **Сервисы** — интерфейсы платформ (реклама, сохранения, аналитика, покупки и др.) с выбором реализации через `ServiceSelector` в зависимости от платформы (YandexGames, GamePush)
- **Работа с Google-таблицами** — загрузка любых данных из Google-таблиц и сохранение в ScriptableObject
- **Встроенная локализация** - гибкая система локализации, основанная на загрузке данных из Google-таблиц
